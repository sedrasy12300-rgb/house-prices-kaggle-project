# House Prices Prediction

## About the Project

This project predicts house prices using Machine Learning based on the Kaggle House Prices dataset.

### Project Steps
- Data cleaning and handling missing values.
- Feature Engineering.
- Converting categorical features into numerical values.
- Training multiple machine learning models.
- Hyperparameter tuning using GridSearchCV.
- Generating predictions for the test dataset.
- Creating a submission file for Kaggle.

### Models Used
- Random Forest Regressor
- Gradient Boosting Regressor

### Tools & Libraries
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Joblib

### Kaggle Result
- Score: 0.15356
- https://www.kaggle.com/c/house-prices-advanced-regression-techniques

This project represents a complete machine learning workflow, from data preprocessing to model training and Kaggle submission.
